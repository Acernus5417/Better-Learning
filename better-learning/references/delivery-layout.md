# 交付结构与收尾

教学产物全部生成后，运行收尾把课程整理成可交付形态。收尾分两步：**停止子 Agent**（主代理执行）和 **package**（脚本执行）。

## 一、转写完成后先停止子 Agent

`assemble` 成功即表示所有来源已合成，此时不应再有成员在写文件。主代理必须按 [宿主适配](host-adapter.md) 里该宿主的 `stopped` 方式确认所有成员已结束：

| 宿主 | 停止方式 |
| --- | --- |
| codex | 用宿主接口确认成员线程已结束，必要时将其终止 |
| codebuddy | 用 `send_message` 发 `shutdown_request`，确认后 `team_delete` 清理团队 |
| claude | 用 `TaskStop` 停止，或确认该 subagent 已返回 |

`package` 会拒绝在有活跃租约（`_工作区/转写任务.json` 里的 `active_member`）时执行，所以这一步不能跳过。同理 `assemble` 也不会在有 `dispatched` 单元时通过——两者互为前置。

## 二、package：清理与归置

```text
python -X utf8 SKILL/scripts/convert_materials.py --course COURSE package --dry-run
python -X utf8 SKILL/scripts/convert_materials.py --course COURSE package
```

先 `--dry-run` 预览将删除与移动的内容，确认后再执行。

**删除**（中间产物，正文已由合成文件承载）：

| 路径 | 说明 |
| --- | --- |
| `资料转写/_分片/` | 批次分片，已并入来源转写 |
| `_工作区/派发提示/` | 成员提示词，一次性 |
| `_工作区/提取内容/` | 逐页渲染图、文本块、单元转写副本、识别证据——**体积主体** |

**保留**：`_工作区/` 下的台账与索引（`转写任务.json`、`资料索引.json`、`章节索引.json`、`知识索引.jsonl`、`覆盖台账.jsonl`、`生成进度.json`、`结构检查.json`），供追溯与审计。

**归置**：把报告与说明类 Markdown 移入 `课程文档/`，并重算所有学习者可见 Markdown 的相对链接。

## 三、最终交付结构

```text
课程包/
├── 开始学习.md              ← 学习者入口
├── 核心知识点.md            ← 卡片
├── 学习文档/                ← 讲义
│   └── 01-第1讲-….md
├── 资料转写/                ← 只保留整合后的完整版
│   └── SRC-001-名称-哈希-agent-v1.md
├── 课程文档/                ← 报告与说明
│   ├── 学习需求.md
│   ├── 学习路径.md
│   ├── 资料清单.md
│   ├── 知识内容.md
│   ├── 质量报告.md
│   ├── 待核实问题.md
│   ├── 学习反馈.md
│   └── 转写拆分计划.md
└── _工作区/                 ← 仅台账与结构检查，无中间产物
```

**外层只放学习者直接要用的三样**：`开始学习.md`、`核心知识点.md`、`学习文档/`；`资料转写/` 作为溯源附件保留整合版。

## 四、体积效果

实测参考包（60 页扫描教材，含 60 个单元渲染图）：

| 项 | 体积 |
| --- | --- |
| `_工作区/`（清理前） | 34.0 MB |
| 全部交付物 | 0.6 MB |
| 过程文件占比 | **98.3%** |

`package` 后包体积约为原来的 1/50。

## 五、打包后的限制

`package` 是**终态动作**：

- 中间产物已按设计删除，`assemble` 等依赖单元文件的操作不再可用；
- `check` 检测到 `packaged` 标记且提取目录已清空时直接返回通过（结构检查结果已存入 `_工作区/结构检查.json`）；
- 如需增补资料，重新走 `inventory` → `prepare` 流程，不要在已打包的包上续接。

## 六、链接安全

`package` 会重算所有学习者可见 Markdown 的相对链接，并保持以下内容不变：

- 围栏代码块与行内代码内的文本；
- 外部链接（`http` / `https` / `mailto` / `data`）；
- 锚点（`#...`）与查询串（`?...`）；
- 指向未被移动文件的链接。

实测（`学习文档/01-第1讲.md` 引用被移动的文档）：

| 原链接 | 打包后 |
| --- | --- |
| `../学习需求.md` | `../课程文档/学习需求.md` |
| `../知识内容.md#k-000001` | `../课程文档/知识内容.md#k-000001` |
| `../核心知识点.md`（未移动） | 不变 |
| `https://x.com/a.md` | 不变 |

**打包前应已通过 `validate_package.py`**——它检查链接可达性，能在移动前发现断链；`package` 只负责搬家，不负责修复本来就断的链接。
