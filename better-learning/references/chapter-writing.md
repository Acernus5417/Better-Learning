# 章节学习文档规范

输入为扫描件时，先完成 [纯图像阅读](image-first.md)，再使用已核查的文字中间层正常按章写作。上下文足够时直接保存整章；仅在实际容量不足或中断时按小节续写，不人为限制单次字数，不省略九块闭环或缩成交付提纲。

根据用户提供的《章节学习文档规范-v2》整理。目标是学生合上其他材料后，仍能完成“理解 → 练习 → 自测 → 纠错 → 复习”。本规范与模板适用于不同学科；无公式的内容不生造公式、单位或数值量级。

## 章级结构

按顺序：章首导引 → 学习目标 → 前置知识与自测 → 术语/符号 → 各节 → 章末知识结构及跨章联系 → 公式/定理或规则速查 → 章末自测及典型题 → 复习与反馈 → 来源。

- 导引约 100–200 字：讲什么、课程位置、前后关系和学习主线，不写空洞强调。
- 目标 3–6 项，用能解释、识别、计算、判断、应用等可观察行为，标记能力层级；每项对应实际题目 ID。
- 前置不能仅列名词。给简明回顾、使用位置、包内补学链接和 2–4 道诊断题，答案另区，明确过关分支。判断阈值要与题数相符；关键概念失败不能被其他题凑分掩盖。
- 术语表含规范中文、英文/别名、符号、单位（适用时）、首次出现、易混对象判据。首次解释不依赖学生查书。

## 每节九块闭环

1. **要解决的问题**：从具体需求、现象或矛盾切入。
2. **知识要点**：准确正式定义、规律、定理及适用/失效条件；公式使用 LaTeX，紧跟符号和单位。正文包含知识 ID 锚点。
3. **深度解析**：为什么、关键推导、何时使用、何时不用、与相邻概念的区别。不得用“显然”代替必要步骤。
4. **例题**：1–2 道，题目先出现，答案独立区；解答包含思路、关键步骤、结论与方法选择理由。计算结果给单位并核算，论述题给可接受论据与判断标准。
5. **易错辨析**：3–5 条，表格写错误说法、错因、诊断提示和正确表述。至少一道自测能暴露其中一项；错误类别按学科适配。
6. **本节自测**：复述/识别、基础应用、变式/迁移各 1 题，只考已解释内容和明确先修内容。
7. **答案解析**：与题干分区，给参考答案、理由、常见错因及前置缺口判断。
8. **过关标准**：可观察能力及具体未通过动作，指向本包章节或练习。
9. **来源**：源文件、章节、物理页/幻灯片/内部位置；区分解释性改写、原文短引、译文及 AI 补充。给相关核心卡片链接，生成卡片后回填。

节正文以约 600–1500 字为节奏参考，章正文约 4000–7000 字（不含题目与答案）。完整性优先；章过大拆成教学章或学习节，简单内容不凑字数。

## 章末与复习

- 用依赖关系图或表显示前置、本章、后续；跨学科联系说明对当前学习的帮助。
- 至少一个能走通的应用案例。类比必须说明成立结构及失效边界，没有可靠类比用具体案例/反例。
- 核心公式/规则速查只复习正文已讲内容，并链接到对应节。
- 章末 3 道分层自测及 3–4 道典型题，覆盖基础、变式和综合；标记知识 ID、能力层级、难度，答案独立。
- 复习计划包含时点、内容、具体题目和达标标志；反馈入口指向 `学习反馈.md`，提供概念不清、会背不会用、步骤不稳的不同回看路径。

## 排版与事实

题干与答案不能并排。通用 Markdown 默认答案独立成区；支持 HTML 折叠时可用 `<details>`，确认阅读器支持后再依赖折叠效果。不能声称任何阅读器都能保证答案不在同屏；要求严格隐藏时将答案另存并链接。

所有必要图示保存在包内 `附件/`，注明来源，并将坐标、图例、关系和适用条件转述到正文。不要让关键理解依赖跳回原件。公式用 `$...$` 或 `$$...$$`，不放代码块；无数学表达不硬造公式。

保留材料中的全部独立知识，但不逐字复刻大段教材。材料未覆盖、无法辨识、存在冲突逐处标记。可靠前置补充可以教学性改写并标为 AI 补充；无法确认的关键知识不编造。关键缺口未解决时该章标为受限，不当作完整教学交付。
