# 学习路径规范

使用 `学习需求.md`、全部知识条目的精简索引和必要章节分片规划。默认生成完整路线，不让考试重点筛选导致知识库内容消失。

1. 为每条可验证学习目标匹配知识和后续练习。
2. 识别必须先掌握的依赖，区别“必要前置”和“有帮助的关联”。必要前置构成有向无环图；循环先判断是否应合并概念或拆出更基础单元。
3. 对已知缺口生成包内补学章节。基础未知者提供诊断分支；基础已证实者可跳过复习，不跳过真正的必要前置。
4. 先按依赖排序，同一依赖层再按由易到难、目标相关性和认知负担排序。源材料章序可以调整，但保留来源映射。
5. 为每章记录目标、先修入口、覆盖知识 ID、预计时间范围、练习量、过关标准、未通过的补学入口及后续章节。
6. 时间紧时标记“主修 / 选学 / 延后”，保留完整路线和知识去向。不要偷偷省略例题、答案或前置补学。

路径使用相对链接指向真实文件和锚点。尚未生成时可在工作计划中记录路径，但交付前必须检查存在。不要链接到不存在的模拟卷、题库、外部课程或卡片；没有相应产物就链接包内实际练习。

知识依赖可用 Mermaid 或关系表展示，必须表达先学方向，不仅画术语树。每章最终目标要能在章内被自测或综合题验证。

时间采用合理范围并说明包括阅读、练习还是复习，不保证每个学生按该时间掌握。复习建议可用当天、第 3 天、第 7 天和考前，根据用户时间调整。
