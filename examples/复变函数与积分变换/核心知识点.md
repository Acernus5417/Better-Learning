## 复数的概念、共轭与四则运算

| 字段 | 内容 |
| --- | --- |
| ID / 覆盖知识 ID | KP-01-01-01 / K-000001、K-000002、K-000003、K-000004 |
| 别名 / 英文 | 复数运算 / complex number arithmetic, conjugate |
| 课程 / 章-节 | 复变函数与积分变换 / 第 1 章 §1.1 |
| 能力层级 / 难度 | 应用 / 低 |
| 掌握度 / 置信度 | 未接触 / 低 |
| 来源 / 最近更新 | SRC-001 U00002–U00003（原 PDF 16–19 页） / 2026-09-15 |

### 1. 术语对齐
- 学术含义：复数域 $\mathbb{C}=\{x+\mathrm{i}y\mid x,y\in\mathbb{R}\}$，$\mathrm{i}^2=-1$。
- 课程含义：一切复分析问题的算术底座；第二章 C-R 方程就是把复等式拆成实部虚部两组得到的。
- 考试识别线索：题目出现 $\mathrm{i}$、$\bar z$、$\operatorname{Re}$、$\operatorname{Im}$，或要求“计算 / 化简 / 求实部虚部 / 解复数方程”。
- 速览三行：**定义** $z=x+\mathrm{i}y$；**条件** 无（除法需分母非零）；**最易混** $\operatorname{Im}z$ 是实数，不是 $\mathrm{i}y$。

### 2. 先学：前置知识
- 前置卡：无（本卡是包内起点）。
- 快速回顾：实数四则运算；$\mathrm{i}^2=-1$ 可直接代入展开；分式化简用“分子分母同乘同一个非零量”。
- 前置自测：Q1. 展开 $(2-3\mathrm{i})(2+3\mathrm{i})$。Q2. 把 $\dfrac{1}{1+\mathrm{i}}$ 化成 $a+b\mathrm{i}$。
- 前置自测答案（独立区）：A1. $4-9\mathrm{i}^2=13$。A2. $\dfrac{1-\mathrm{i}}2=\dfrac12-\dfrac12\mathrm{i}$。
- 补齐路径：两题都错则回看 [第 1 讲 §1.1](学习文档/01-复数与复变函数.md#s1-1)。

### 3. 在学：直观理解
- 解决的问题：实数里 $x^2=-1$ 无解，需要一个加减乘除都封闭的数系。
- 一句话解释：把复数看成“一对实数 $(x,y)$ 加上一套规定的乘法”，$\mathrm{i}$ 只是这套乘法的记账符号。
- 过程（除法）：写 $z=x+\mathrm{i}y$ → 展开 $z_2z=z_1$ → 用“实部虚部分别相等”得二元方程组 → 解出。
- 具体案例：$z_1=3-2\mathrm{i}$、$z_2=2+3\mathrm{i}$ 时 $z_1z_2=12+5\mathrm{i}$。
- 类比与边界：与平面上的点对应很好用，但**不能**把复数当向量做点积或叉积。

### 4. 在学：正式定义与公式或规则
- 定义：$z=x+\mathrm{i}y$，$\operatorname{Re}z=x$，$\operatorname{Im}z=y$；$\bar z=x-\mathrm{i}y$；$z=0\iff x=y=0$。
- 公式：

$$z_1\pm z_2=(x_1\pm x_2)+\mathrm{i}(y_1\pm y_2),\qquad z_1z_2=(x_1x_2-y_1y_2)+\mathrm{i}(x_1y_2+x_2y_1),$$
$$\frac{z_1}{z_2}=\frac{z_1\bar z_2}{z_2\bar z_2}\ (z_2\ne0),\qquad \overline{z_1z_2}=\bar z_1\bar z_2,\qquad z\bar z=|z|^2,$$
$$\operatorname{Re}z=\frac12(z+\bar z),\qquad \operatorname{Im}z=\frac{1}{2\mathrm{i}}(z-\bar z).$$

- 符号与单位：$\operatorname{Re}$、$\operatorname{Im}$ 取实数，无单位。
- 条件与失效：除法需 $z_2\ne0$；复数**不能比较大小**。
- 推理主线：先定义加、乘，再由逆运算定义减、除；$x+\mathrm{i}y$ 等于“$\mathrm{i}$ 乘 $y$ 再加 $x$”是定义的结果。
- 易混区别：$\overline{z_1\bar z_2}=\bar z_1z_2$（两次共轭抵消），不是 $\bar z_1\bar z_2$。

### 5. 典型例子
**例 1** 计算 $\dfrac{3-2\mathrm{i}}{2+3\mathrm{i}}$。**例 2** 求 $\dfrac{z-1}{z+1}$（$z=x+\mathrm{i}y\ne-1$）的实部与虚部。

#### 例题答案区
例 1：同乘 $2-3\mathrm{i}$，得 $\dfrac{6-9\mathrm{i}-4\mathrm{i}+6\mathrm{i}^2}{13}=\dfrac{-13\mathrm{i}}{13}=-\mathrm{i}$。方法理由：分母有理化一次到位，比背公式更稳。
例 2：分母有理化得 $\dfrac{x^2+y^2-1+2y\mathrm{i}}{(x+1)^2+y^2}$，故实部 $\dfrac{x^2+y^2-1}{(x+1)^2+y^2}$，虚部 $\dfrac{2y}{(x+1)^2+y^2}$。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| $\operatorname{Im}(3+4\mathrm{i})=4\mathrm{i}$ | 忘记虚部是实数 | 结果含 $\mathrm{i}$ 吗 | $\operatorname{Im}=4$ |
| 乘积实部写成 $x_1x_2$ | 漏掉 $-y_1y_2$ | 有减号吗 | $x_1x_2-y_1y_2$ |
| $\mathrm{i}>0$ | 把 $\mathbb{R}$ 的序搬到 $\mathbb{C}$ | 在做大小比较吗 | 复数无序 |
| $\operatorname{Im}z=\dfrac{z-\bar z}{2}$ | 分母漏 $\mathrm{i}$ | 分母有 $\mathrm{i}$ 吗 | $\dfrac{z-\bar z}{2\mathrm{i}}$ |

- 具体反例：$z=1+\mathrm{i}$ 与 $w=1-\mathrm{i}$ 的模相同，但 $z\ne w$——模相同不等于相等。

### 7. 后续关联
- 后续卡：[KP-01-02-01](#KP-01-02-01)（用到 $z\bar z=|z|^2$）、[KP-02-01-02](#KP-02-01-02)（C-R 方程即拆实虚部）。
- 讲义入口：[第 1 讲 §1.1](学习文档/01-复数与复变函数.md#s1-1)。
- 跨学科：电工程把 $\mathrm{i}$ 写作 $\mathrm{j}$，表示 $90^\circ$ 相移。

### 8. 自测与答案解析
- Q1（复述/识别）：写出 $\operatorname{Re}z$、$\operatorname{Im}z$ 用 $z,\bar z$ 表示的式子。
- Q2（基础应用）：计算 $(a-\mathrm{i}b)^3$，整理为 $A+\mathrm{i}B$。
- Q3（迁移）：已知 $z_1+z_2$ 与 $z_1z_2$ 都是实数且 $z_1\ne z_2$，能否断定 $z_2=\bar z_1$？

我的回答：
我不确定的地方：

#### 自测答案区
- A1：$\operatorname{Re}z=\frac12(z+\bar z)$，$\operatorname{Im}z=\frac{1}{2\mathrm{i}}(z-\bar z)$。
- A2：$(a^3-3ab^2)+\mathrm{i}(b^3-3a^2b)$。
- A3：能。$z_1,z_2$ 是实系数二次方程 $z^2-Sz+P=0$（$S,P\in\mathbb{R}$）的两根，故互为共轭；由 $z_1\ne z_2$ 得 $z_2=\bar z_1$。常见错因：只用“和为实数”就下结论。
  前置缺口：不会用韦达定理 → 复习一元二次方程根与系数的关系。

### 9. 课程位置与考核入口
- 讲义节：[第 1 讲 §1.1](学习文档/01-复数与复变函数.md#s1-1)；练习：自测 1-1、习题一 1.1–1.3、章末 T1-1。题型：计算与化简，属必得分题。

### 10. 来源与证据
- 定位：SRC-001 / U00002–U00003（原 PDF 第 16–19 页）。外部核查：无。AI 补充：自测 Q3 为教学性自拟。冲突与修订：无。

### 11. 掌握度快照
- 当前等级：未接触；置信度：低。最近真实证据：无。
- 卡点（预期）：$\operatorname{Im}$ 的含义；$\overline{(z_1\bar z_2)}$ 的两次共轭。
- 下一步：做自测 Q1–Q3 并记录错因。日期：2026-09-15。

## 复平面、模与辐角、三角表示

| 字段 | 内容 |
| --- | --- |
| ID / 覆盖知识 ID | KP-01-02-01 / K-000005、K-000006、K-000008 |
| 别名 / 英文 | 模与辐角 / modulus and argument, polar form |
| 课程 / 章-节 | 复变函数与积分变换 / 第 1 章 §1.1.3、§1.2.1、§1.2.3 |
| 能力层级 / 难度 | 应用 / 中 |
| 掌握度 / 置信度 | 未接触 / 低 |
| 来源 / 最近更新 | SRC-001 U00003–U00004（原 PDF 19–25 页） / 2026-09-15 |

### 1. 术语对齐
- 学术含义：$|z|=\sqrt{x^2+y^2}$；$\operatorname{Arg}z$ 多值，$\arg z$ 为主辐角（单值，$-\pi<\arg z\leqslant\pi$）。
- 课程含义：把复数从直角坐标换成极坐标，为乘除乘方开方提供统一入口。
- 考试识别线索：“求模、求辐角主值、写成三角（极）表示、$|z-z_0|$”。
- 速览三行：**定义** $z=r(\cos\theta+\mathrm{i}\sin\theta)$；**条件** $z\ne0$ 才有辐角；**最易混** $\operatorname{Arg}$（大写多值）与 $\arg$（小写主值）。

### 2. 先学：前置知识
- 前置卡：[KP-01-01-01](#KP-01-01-01)。
- 快速回顾：平面直角坐标、勾股定理；$\arctan$ 值域为 $\left(-\dfrac\pi2,\dfrac\pi2\right)$。
- 前置自测：Q1. 点 $(-2,2)$ 到原点距离？在第几象限？Q2. $x<0,y>0$ 时 $\arctan\dfrac yx$ 落在第几象限？
- 前置自测答案（独立区）：A1. $2\sqrt2$，第二象限。A2. 第四象限，须加 $\pi$。
- 补齐路径：出错则回看 [第 1 讲 §1.2](学习文档/01-复数与复变函数.md#s1-2) 主辐角分段公式。

### 3. 在学：直观理解
- 解决的问题：复数乘法在直角坐标下看不出几何意义。
- 一句话解释：复数 = 长度 + 方向；长度是模，方向是辐角。
- 过程：由 $x=r\cos\theta$、$y=r\sin\theta$ 得三角表示；求辐角必须先判象限。
- 具体案例：$1+\mathrm{i}=\sqrt2\left(\cos\dfrac\pi4+\mathrm{i}\sin\dfrac\pi4\right)$。
- 反例：$z=0$ 时 $|z|=0$ 但辐角不存在，不能写三角表示。
- 类比边界：与向量的“长度 + 方向”类比成立；但向量可平移，只有起点在原点时才与复数一致。

### 4. 在学：正式定义与公式或规则
$$\operatorname{Arg}z=\arg z+2k\pi,\quad -\pi<\arg z\leqslant\pi;\qquad |z|=\sqrt{x^2+y^2},\quad z\bar z=|z|^2,\quad \frac1z=\frac{\bar z}{|z|^2};$$
$$\arg z=\begin{cases}\arctan\frac yx, & x>0;\\[1ex]\frac\pi2, & x=0,\ y>0;\\[1ex]\arctan\frac yx+\pi, & x<0,\ y\geqslant0;\\[1ex]\arctan\frac yx-\pi, & x<0,\ y<0;\\[1ex]-\frac\pi2, & x=0,\ y<0.\end{cases}$$
- 三角表示：$z=r(\cos\theta+\mathrm{i}\sin\theta)$；两个三角表示相等 $\Rightarrow$ $r_1=r_2$、$\theta_1=\theta_2+2k\pi$。
- 条件与失效：$z\ne0$；$|\bar z|=|z|$，$\arg\bar z=-\arg z$（负实数例外，$\arg=\pi$）。
- 课程约定：主辐角取 $(-\pi,\pi]$；部分教材取 $[0,2\pi)$。
- 易混区别：$|z_1-z_2|$ 是两点距离，不是 $|z_1|-|z_2|$。

### 5. 典型例子
**例 1** 写 $-1-3\mathrm{i}$ 的三角表示。**例 2** 求 $\dfrac1z$（$z=r(\cos\theta+\mathrm{i}\sin\theta)$）的三角表示。

#### 例题答案区
例 1：$|-1-3\mathrm{i}|=\sqrt{10}$，第三象限，$\arg=\arctan3-\pi$，故 $-1-3\mathrm{i}=\sqrt{10}\left[\cos(\arctan3-\pi)+\mathrm{i}\sin(\arctan3-\pi)\right]$。
例 2：$\dfrac1z=\dfrac{\bar z}{|z|^2}=\dfrac1r\left[\cos(-\theta)+\mathrm{i}\sin(-\theta)\right]$。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| $\arg(-1-3\mathrm{i})=\arctan3$ | 忘记象限修正 | 在第几象限 | 第三象限用 $\arctan3-\pi$ |
| $\operatorname{Arg}z$ 是单值 | 混淆大小写 | 大写还是小写 | $\operatorname{Arg}$ 多值 |
| $|z_1-z_2|=|z_1|-|z_2|$ | 把距离当差的模 | 两个竖线套一起了吗 | $||z_1|-|z_2||\leqslant|z_1-z_2|$ |
| $\arg\bar z=\arg z$ | 共轭反号 | 是负实数吗 | 一般 $\arg\bar z=-\arg z$ |

- 具体反例：$z=-\mathrm{i}$ 的 $\arg=-\dfrac\pi2$，而 $\bar z=\mathrm{i}$ 的 $\arg=\dfrac\pi2$，正好反号。

### 7. 后续关联
- 后续卡：[KP-01-02-03](#KP-01-02-03)、[KP-01-02-04](#KP-01-02-04)、[KP-02-03-01](#KP-02-03-01)。
- 讲义入口：[第 1 讲 §1.2](学习文档/01-复数与复变函数.md#s1-2)。
- 跨学科：平面场、傅里叶变换的模-相角表示（样本外）。

### 8. 自测与答案解析
- Q1（复述/识别）：写出模、主辐角定义与分段公式。
- Q2（基础应用）：求 $2-\mathrm{i}$ 的模、主辐角与三角表示。
- Q3（迁移）：设 $\arg z=\dfrac\pi6$、$|z|=2$，求 $z$，并说明 $\arg\bar z$ 与 $\arg(z^{-1})$ 的关系。

我的回答：
我不确定的地方：

#### 自测答案区
- A1：见第 4 块。
- A2：$|2-\mathrm{i}|=\sqrt5$，$\arg=-\arctan\dfrac12$，故 $2-\mathrm{i}=\sqrt5\left[\cos\left(-\arctan\dfrac12\right)+\mathrm{i}\sin\left(-\arctan\dfrac12\right)\right]$。
- A3：$z=\sqrt3+\mathrm{i}$。$\arg\bar z=-\dfrac\pi6$，$\arg(z^{-1})=-\arg z=-\dfrac\pi6$（两者辐角相同）。
  常见错因：把 $2-\mathrm{i}$ 当第一象限；以为 $z^{-1}$ 的辐角等于 $\arg z$。
  前置缺口：Q2 错 → 回看 [第 1 讲 §1.2](学习文档/01-复数与复变函数.md#s1-2) 例 1-B。

### 9. 课程位置与考核入口
- 讲义节：[第 1 讲 §1.2](学习文档/01-复数与复变函数.md#s1-2)；练习：自测 1-2 Q1、习题一 1.6、1.8、章末 T1-2。题型：计算与表示题，必考基础题。

### 10. 来源与证据
- 定位：SRC-001 / U00003–U00004（原 PDF 第 19–25 页）；图 1.3、1.4 已按图注转述。AI 补充：自测 Q3 为教学性自拟。冲突与修订：教材脚注说明主辐角约定与本课程不同，本卡按 $(-\pi,\pi]$。

## 复数模的三角不等式

| 字段 | 内容 |
| --- | --- |
| ID / 覆盖知识 ID | KP-01-02-02 / K-000007 |
| 别名 / 英文 | 三角不等式 / triangle inequality |
| 课程 / 章-节 | 复变函数与积分变换 / 第 1 章 §1.2.2 |
| 能力层级 / 难度 | 理解 / 应用 / 中 |
| 掌握度 / 置信度 | 未接触 / 低 |
| 来源 / 最近更新 | SRC-001 U00003（原 PDF 22–24 页） / 2026-09-15 |

### 1. 术语对齐
- 学术含义：模的次可加性，等价于平面上的三角形不等式。
- 课程含义：全课程唯一的“估计/放缩”工具，第三章估计积分、第五章估计留数都要用。
- 考试识别线索：“证明不等式”“估计”“最大值”“$|z|\leqslant$”。
- 速览三行：**定义** $||z_1|-|z_2||\leqslant|z_1\pm z_2|\leqslant|z_1|+|z_2|$；**条件** 无条件，等号需过原点共线；**最易混** 复数本身不能比大小。

### 2. 先学：前置知识
- 前置卡：[KP-01-01-01](#KP-01-01-01)、[KP-01-02-01](#KP-01-02-01)。
- 快速回顾：$|z|^2=z\bar z$；$\operatorname{Re}w\leqslant|w|$。
- 前置自测：Q1. 写出 $|z_1+z_2|^2$ 的展开前两步。Q2. $\operatorname{Re}(z_1\bar z_2)$ 与 $|z_1||z_2|$ 哪个大？

### 3. 在学：直观理解
- 解决的问题：如何不用坐标就把“和的模”控制住。
- 一句话解释：三角形两边之和大于第三边、之差小于第三边。
- 过程：展开 $|z_1+z_2|^2$ → 把 $\operatorname{Re}(z_1\bar z_2)$ 换成 $\pm|z_1||z_2|$ → 开方。
- 具体案例：$z_1=3+4\mathrm{i}$、$z_2=\mathrm{i}$ 时 $|z_1+z_2|=\sqrt{34}\approx5.83<6$。
- 反例：$z_1=1$、$z_2=-1$ 时取到 $\bigl||z_1|-|z_2|\bigr|=0$。
- 类比边界：成立前提是“模即距离”；不能把 $|z_1-z_2|$ 与 $|z_1|-|z_2|$ 混同。

### 4. 在学：正式定义与公式或规则
$$||z_1|-|z_2||\leqslant|z_1-z_2|\leqslant|z_1|+|z_2|,\qquad ||z_1|-|z_2||\leqslant|z_1+z_2|\leqslant|z_1|+|z_2|.$$

- 推理主线：共轭展开 + $|\operatorname{Re}w|\leqslant|w|$ 同时给出上下界。
- 易混区别：外层双竖线不可省，否则会出现负数上界。

### 5. 典型例子

## 三角表示下的乘除与乘方（棣莫弗公式）

| 字段 | 内容 |
| --- | --- |
| ID / 覆盖知识 ID | KP-01-02-03 / K-000009、K-000010 |
| 别名 / 英文 | 乘法几何意义、De Moivre 公式 / multiplication, De Moivre's formula |
| 课程 / 章-节 | 复变函数与积分变换 / 第 1 章 §1.2.4、§1.2.5 |
| 能力层级 / 难度 | 应用 / 中 |
| 掌握度 / 置信度 | 未接触 / 低 |
| 来源 / 最近更新 | SRC-001 U00003（原 PDF 25–28 页） / 2026-09-15 |

### 1. 术语对齐
- 学术含义：$z_1z_2$ 的模相乘、辐角相加；由此得 $z^n=r^n(\cos n\theta+\mathrm{i}\sin n\theta)$。
- 课程含义：把乘法变成“旋转 + 伸缩”，是第六章共形映射与工程相量法的直观来源。
- 考试识别线索：“用三角表示计算”“求 $z^n$”“用棣莫弗公式证明倍角公式”。
- 速览三行：**定义** 模相乘、角相加；**条件** 除法需分母非零；**最易混** $\operatorname{Arg}$ 等式是多值相等。

### 2. 先学：前置知识
- 前置卡：[KP-01-02-01](#KP-01-02-01)、[KP-01-01-01](#KP-01-01-01)。
- 快速回顾：两角和公式；$|\mathrm{i}|=1$，$\arg\mathrm{i}=\dfrac\pi2$。
- 前置自测：Q1. 写出两角和的正弦、余弦公式。Q2. $\mathrm{i}z$ 把 $z$ 的向量怎样移动？
- 前置自测答案（独立区）：A1. $\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta$，$\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta$。A2. 逆时针转 $\dfrac\pi2$，长度不变。
- 补齐路径：出错则回看 [第 1 讲 §1.2](学习文档/01-复数与复变函数.md#s1-2) 的 (1.7) 推导。

### 3. 在学：直观理解
- 解决的问题：$z_1z_2$ 的直角坐标公式看不出意义。
- 一句话解释：复数相乘 = 长度相乘、方向相加。
- 过程：三角表示相乘 → 两角和公式合并 → (1.7)；迭代 $n-1$ 次 → 乘方公式。
- 具体案例：$\mathrm{i}(1+\mathrm{i})=-1+\mathrm{i}$：逆时针转 $90^\circ$。
- 反例：$(1+\sqrt3\mathrm{i})(-\sqrt3-\mathrm{i})=-4\mathrm{i}$（模 $4$，角 $-\dfrac\pi2$）。
- 类比边界：与“旋转算子”类比成立；但复数乘法不等于向量的点积或叉积。

### 4. 在学：正式定义与公式或规则
$$z_1z_2=r_1r_2[\cos(\theta_1+\theta_2)+\mathrm{i}\sin(\theta_1+\theta_2)],\quad |z_1z_2|=|z_1||z_2|,\quad \operatorname{Arg}(z_1z_2)=\operatorname{Arg}z_1+\operatorname{Arg}z_2;$$
$$\frac{z_1}{z_2}=\frac{r_1}{r_2}[\cos(\theta_1-\theta_2)+\mathrm{i}\sin(\theta_1-\theta_2)],\qquad z^n=r^n(\cos n\theta+\mathrm{i}\sin n\theta);$$
$$(\cos\theta+\mathrm{i}\sin\theta)^n=\cos n\theta+\mathrm{i}\sin n\theta\quad(\text{棣莫弗公式}).$$
- 条件与失效：$n$ 为正整数（教材范围）；除法需 $z_2\ne0$。
- 推理主线：乘法定义 + 两角和公式 → (1.7)。
- 易混区别：$\operatorname{Arg}$ 的加减等式是多值相等，不能按单值式移项消去。

### 5. 典型例子
**例 1** 用三角表示计算 $(1+\sqrt3\mathrm{i})(-\sqrt3-\mathrm{i})$。**例 2** 计算 $(1+\sqrt3\mathrm{i})^3$。

#### 例题答案区
例 1：$1+\sqrt3\mathrm{i}=2\left(\cos\dfrac\pi3+\mathrm{i}\sin\dfrac\pi3\right)$，$-\sqrt3-\mathrm{i}=2\left[\cos\left(-\dfrac56\pi\right)+\mathrm{i}\sin\left(-\dfrac56\pi\right)\right]$，乘积 $=4\left[\cos\left(-\dfrac\pi2\right)+\mathrm{i}\sin\left(-\dfrac\pi2\right)\right]=-4\mathrm{i}$。
例 2：$=\left[2\left(\cos\dfrac\pi3+\mathrm{i}\sin\dfrac\pi3\right)\right]^3=8(\cos\pi+\mathrm{i}\sin\pi)=-8$。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| 乘法时模相加 | 混淆两套法则 | 模该乘还是加 | 模相乘、角相加 |
| 对 (1.9) 两边减 $\operatorname{Arg}z_1$ | 当单值等式 | 是多值吗 | 按多值对应理解 |
| $(\cos\theta+\mathrm{i}\sin\theta)^n=\cos^n\theta+\mathrm{i}\sin^n\theta$ | 逐项乘幂 | 指数作用对象 | $=\cos n\theta+\mathrm{i}\sin n\theta$ |
| $\mathrm{i}z$ 顺时针转 | 方向记反 | $\arg\mathrm{i}$ 正负 | 逆时针 $90^\circ$ |

- 具体反例：$\mathrm{i}^2=-1$，是逆时针转两次 $90^\circ$，与定义一致。

### 7. 后续关联
- 后续卡：[KP-01-02-04](#KP-01-02-04)、[KP-02-03-01](#KP-02-03-01)。
- 讲义入口：[第 1 讲 §1.2](学习文档/01-复数与复变函数.md#s1-2)。

## 复数的开方

| 字段 | 内容 |
| --- | --- |
| ID / 覆盖知识 ID | KP-01-02-04 / K-000011 |
| 别名 / 英文 | n 次方根、多值性 / n-th roots |
| 课程 / 章-节 | 复变函数与积分变换 / 第 1 章 §1.2.5 |
| 能力层级 / 难度 | 应用 / 中 |
| 掌握度 / 置信度 | 未接触 / 低 |
| 来源 / 最近更新 | SRC-001 U00003–U00004（原 PDF 28–29 页） / 2026-09-15 |

### 1. 术语对齐
- 学术含义：$w^n=z$ 的全部解；非零复数的 $n$ 次方根恰有 $n$ 个。
- 课程含义：教材本章小结明确列为“复数与实数运算不一样的新问题”，概念题常客。
- 考试识别线索：“求 $\sqrt[n]{z}$”“解方程 $z^n=a$”“根的个数与位置”。
- 速览三行：**定义** $z^{1/n}$ 是满足 $w^n=z$ 的 $w$；**条件** $z\ne0$ 时有 $n$ 个根，$z=0$ 时只有 $0$；**最易混** 复数中 $\sqrt[n]{z}$ 不是算术根。

### 2. 先学：前置知识
- 前置卡：[KP-01-02-03](#KP-01-02-03)、[KP-01-02-01](#KP-01-02-01)。
- 快速回顾：$\rho^n=r$ 在正实数中有唯一解；$\mathrm{e}^{\mathrm{i}2k\pi}=1$。
- 前置自测：Q1. 实数中 $\sqrt[3]{8}$ 有几个值？复数中呢？Q2. $2$ 的三个立方根的模是多少？
- 前置自测答案（独立区）：A1. 实数 1 个，复数 3 个。A2. 都等于 $\sqrt[3]2$。
- 补齐路径：出错则回看 [第 1 讲 §1.2](学习文档/01-复数与复变函数.md#s1-2) 的 (1.15) 与例 1.8。

### 3. 在学：直观理解
- 解决的问题：$z^n=a$ 有几个解？怎么一次算全？
- 一句话解释：模开 $n$ 次算术根，辐角平均分成 $n$ 份再加 $\dfrac{2k\pi}{n}$。
- 过程：写三角表示 → 由 $\rho^n=r$、$n\varphi=\theta+2k\pi$ 解得 $\rho,\varphi$ → 取 $k=0,\dots,n-1$。
- 具体案例：$z^3=2$ 的三根模都为 $\sqrt[3]2$，辐角 $0,\dfrac{2\pi}3,\dfrac{4\pi}3$，构成正三角形。
- 反例（几何校验）：若算出的 $n$ 个根模不相等，必然算错。
- 类比边界：实数“开方取算术根”的直觉会误导——复数的根有 $n$ 个且均匀分布。

### 4. 在学：正式定义与公式或规则
$$w=|z|^{1/n}\left[\cos\frac{\arg z+2k\pi}{n}+\mathrm{i}\sin\frac{\arg z+2k\pi}{n}\right],\qquad k=0,1,\cdots,n-1.$$
- 结论：非零复数的 $n$ 次方根恰有 $n$ 个值，构成以原点为中心的正 $n$ 边形顶点，到原点距离 $|z|^{1/n}$，其中一根辐角为 $\dfrac1n\arg z$。
- 条件与失效：$z\ne0$；$z=0$ 时只有 $w=0$。
- 推理主线：比较模与辐角；相差 $2\pi$ 整数倍的 $\varphi$ 对应同一 $w$，故本质不同的角恰 $n$ 个。
- 易混区别：$z^{1/n}$（多值）与实数 $\sqrt[n]{r}$（算术根，单值）。

### 5. 典型例子
**例** 解 $z^3-2=0$。

#### 例题答案区
$z=\sqrt[3]2\left(\cos\dfrac{2k\pi}3+\mathrm{i}\sin\dfrac{2k\pi}3\right)$，$k=0,1,2$，即 $\sqrt[3]2$、$\sqrt[3]2\left(-\dfrac12+\dfrac{\sqrt3}2\mathrm{i}\right)$、$\sqrt[3]2\left(-\dfrac12-\dfrac{\sqrt3}2\mathrm{i}\right)$。方法理由：先化到“模 × (cos + i sin)”，再用正多边形检查个数与分布。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| 只取 $k=0$ | 忽略多值性 | 取到 $n-1$ 了吗 | 取 $k=0,\dots,n-1$ |
| 根的模写成 $|z|^n$ | 把开方当乘方 | 模该开方吗 | $|z|^{1/n}$ |
| 把 $\sqrt[n]{}$ 当算术根 | 实数习惯迁移 | 只给一个值吗 | 复数有 $n$ 个根 |
| $k$ 取超过 $n$ 个值 | 会重复 | 有重复值吗 | 只需 $n$ 个 |

- 具体反例：$\sqrt[4]{1}$ 有 4 个值 $1,\mathrm{i},-1,-\mathrm{i}$，只写 $1$ 就漏了三个。

### 7. 后续关联
- 后续卡：[KP-02-03-03](#KP-02-03-03)、[KP-01-03-01](#KP-01-03-01)。
- 讲义入口：[第 1 讲 §1.2](学习文档/01-复数与复变函数.md#s1-2)。

### 8. 自测与答案解析
- Q1（复述/识别）：说明非零复数 $n$ 次方根的个数与几何位置。
- Q2（基础应用）：求 $\sqrt[4]{-2+2\mathrm{i}}$ 的全部值。
- Q3（迁移）：$(1+\mathrm{i})^{1/2}$ 有几个值？写出一个，并说明它与 $(1+\mathrm{i})^2$ 的区别。

我的回答：
我不确定的地方：

#### 自测答案区

- 曲线：$z(t)=x(t)+\mathrm{i}y(t)$；光滑、简单曲线（无重点）、简单闭曲线（首尾重合）；若尔当定理把平面分成内部与外部。

- 条件与失效：区域必须开；除全平面外闭区域不是区域。
- 易混区别：孤立点一定是边界点（单向）；$|z|>R$ 是区域而 $|z|\geqslant R$ 是闭区域。

## 复变函数、极限与连续

| 字段 | 内容 |
| --- | --- |
| ID / 覆盖知识 ID | KP-01-05-01 / K-000018、K-000019、K-000020 |
| 别名 / 英文 | 复变函数、极限、连续 / complex function, limit, continuity |
| 课程 / 章-节 | 复变函数与积分变换 / 第 1 章 §1.5 |
| 能力层级 / 难度 | 理解 / 应用 / 中 |
| 掌握度 / 置信度 | 未接触 / 低 |
| 来源 / 最近更新 | SRC-001 U00004–U00005（原 PDF 36–41 页） / 2026-09-15 |

### 1. 术语对齐
- 学术含义：$w=f(z)$ 分解为 $u+\mathrm{i}v$；极限要求路径无关；连续要求极限等于函数值。
- 课程含义：复极限的“路径无关”是第二章可导性苛刻的根本原因；$\arg z$ 的断裂决定 $\ln z$ 的解析区域。
- 考试识别线索：“化为一对二元实函数”“求极限”“讨论连续性”“证明极限不存在”。
- 速览三行：**定义** $\lim f=A$ 要求沿任意路径都得 $A$；**条件** $A$ 为有限复数；**最易混** 定义形式与实函数同、实质更严。

### 2. 先学：前置知识
- 前置卡：[KP-01-03-01](#KP-01-03-01)、[KP-01-02-02](#KP-01-02-02)。
- 快速回顾：一元实函数极限与连续的 $\varepsilon$-$\delta$ 定义；$\arg z$ 的多值性。
- 前置自测：Q1. 写出实函数连续的 $\varepsilon$-$\delta$ 定义。Q2. $\arg z$ 在哪条线上从 $\pi$ 跳到 $-\pi$？
- 前置自测答案（独立区）：A1. $\forall\varepsilon>0\exists\delta>0:|x-x_0|<\delta\Rightarrow|f(x)-f(x_0)|<\varepsilon$。A2. 负实轴（原点处无定义）。
- 补齐路径：出错则回看 [第 1 讲 §1.5](学习文档/01-复数与复变函数.md#s1-5)。

### 3. 在学：直观理解
- 解决的问题：复变函数能否像实函数那样讨论极限与连续。
- 一句话解释：形式上一样，但 $z\to z_0$ 有无穷多条路，极限更“难存在”。
- 过程：拆 $f=u+\mathrm{i}v$ → 定理 1.1 化为两个二元实极限 → 需否定时用路径法。
- 具体案例：$\dfrac{\bar z}{z}$ 在 $z=0$ 无极限（沿方向角 $\theta_0$ 得 $\cos(-2\theta_0)+\mathrm{i}\sin(-2\theta_0)$）。
- 反例：$\dfrac{\operatorname{Re}z}{z}$ 沿实轴得 1、沿虚轴得 0。
- 类比边界：有界闭域上连续函数的三条性质与二元实函数一致，可直接照搬。

### 4. 在学：正式定义与公式或规则
$$0<|z-z_0|<\delta\ \Longrightarrow\ |f(z)-A|<\varepsilon\qquad(\text{定义 1.1，}A\ne\infty).$$
- 定理 1.1：$\lim\limits_{z\to z_0}f(z)=A\iff\lim u=u_0$ 且 $\lim v=v_0$（$(x,y)\to(x_0,y_0)$）。
- 含 $\infty$ 的极限：$\lim\limits_{z\to\infty}f(z)=a\iff\lim\limits_{t\to0}f(1/t)=a$；$\lim\limits_{z\to z_0}\dfrac1{f(z)}=0\iff\lim f(z)=\infty$。
- 定义 1.2 与定理 1.2：$f$ 在 $z_0$ 连续 $\iff u,v$ 在 $(x_0,y_0)$ 连续。
- 有界闭域上连续函数：有界、$|f|$ 取到最值各一次、一致连续。
- 条件与失效：$\arg z$ 在原点与负实轴不连续；有理函数在分母零点处不连续。
- 易混区别：定理 1.1 的充分性证明依赖三角不等式 $|f-A|\leqslant|u-u_0|+|v-v_0|$。

### 5. 典型例子
**例 1** 互化 $w=z^2+1$ 与 $u=\dfrac{2x}{x^2+y^2},v=\dfrac{y}{x^2+y^2}$。**例 2** 求证 $\arg z$ 在除去原点与负实轴的区域上连续、在负实轴上不连续。

#### 例题答案区
例 1：$u=x^2-y^2+1$，$v=2xy$；反向得 $w=\dfrac{3}{2\bar z}+\dfrac{1}{2z}$（$z\ne0$），推导见 [第 1 讲 §1.5](学习文档/01-复数与复变函数.md#s1-5) 例 1-F(2)。
例 2：区域内取 $\delta\leqslant|z_0|\sin\varepsilon$ 使 $|\arg z-\arg z_0|<\varepsilon$；负实轴上左右极限为 $\pi$ 与 $-\pi$，不等故不连续。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| 两条路径极限相同就断定存在 | 路径无穷多 | 做到任意路径了吗 | 只能否定不能肯定 |
| 以为复极限定义与实函数完全一样 | 忽略路径数量 | 有几条路 | 形式同、实质更严 |
| $\arg z$ 除原点处处连续 | 漏了负实轴 | 检查负实轴了吗 | 负实轴不连续 |
| 极限存在即连续 | 还要等于函数值 | 有定义吗 | 需 $\lim f=f(z_0)$ |

- 具体反例：$f=\dfrac{xy}{x^2+y^2}$（$z\ne0$）、$f(0)=0$，沿 $y=kx$ 得 $\dfrac{k}{1+k^2}$，随 $k$ 变，故在 $z=0$ 不连续。

### 7. 后续关联
- 后续卡：[KP-02-01-01](#KP-02-01-01)、[KP-02-03-02](#KP-02-03-02)。
- 讲义入口：[第 1 讲 §1.5](学习文档/01-复数与复变函数.md#s1-5)。

## 导数、解析与求导法则

| 字段 | 内容 |
| --- | --- |
| ID / 覆盖知识 ID | KP-02-01-01 / K-000021、K-000023、K-000024 |
| 别名 / 英文 | 可导、解析 / derivative, analytic function |
| 课程 / 章-节 | 复变函数与积分变换 / 第 2 章 §2.1.1、§2.1.2 |
| 能力层级 / 难度 | 应用 / 中 |
| 掌握度 / 置信度 | 未接触 / 低 |
| 来源 / 最近更新 | SRC-001 U00005–U00006（原 PDF 45–51 页） / 2026-09-15 |

### 1. 术语对齐
- 学术含义：$f'(z_0)=\lim\limits_{\Delta z\to0}\dfrac{\Delta w}{\Delta z}$（有限）；解析指在 $z_0$ 及其邻域处处可导。
- 课程含义：解析是本课程的中心概念，后续积分、级数、留数、共形映射都建立在它之上。
- 考试识别线索：“求导数”“解析区域”“是否解析”“奇点”。
- 速览三行：**定义** 差商极限存在且有限；**条件** 解析需**邻域**内处处可导；**最易混** 点可导 ≠ 点解析。

### 2. 先学：前置知识
- 前置卡：[KP-01-05-01](#KP-01-05-01)、[KP-01-03-01](#KP-01-03-01)。
- 快速回顾：连续的定义；一元实函数求导法则。
- 前置自测：Q1. 可导是否一定连续？Q2. 实数中 $|x|$ 在 $0$ 处可导吗？
- 前置自测答案（独立区）：A1. 一定。A2. 不可导，左右导数不等。
- 补齐路径：出错则回看 [第 1 讲 §1.5](学习文档/01-复数与复变函数.md#s1-5)。

### 3. 在学：直观理解
- 解决的问题：什么样的复变函数“好用”。
- 一句话解释：差商极限存在 $\iff$ $\Delta w=f'(z_0)\Delta z+o(|\Delta z|)$，即局部线性近似。
- 过程：算差商 → 极限存在且有限则可导；若差商依赖 $\Delta z$ 的方向则不可导。
- 具体案例：$|z|^2$ 在 $z=0$ 可导（差商 $\bar z\to0$）；$\operatorname{Re}z$ 处处不可导。
- 反例：沿 $\operatorname{Re}z=\operatorname{Re}z_0$ 得 0、沿 $\operatorname{Im}z=\operatorname{Im}z_0$ 得 1。
- 类比边界：与实函数“局部线性近似”类比成立；边界是“复数有多个方向”。

### 4. 在学：正式定义与公式或规则
$$f'(z_0)=\lim_{\Delta z\to0}\frac{f(z_0+\Delta z)-f(z_0)}{\Delta z},\qquad \Delta w=f'(z_0)\Delta z+o(|\Delta z|).$$
- 定义 2.2：解析 / 解析函数 / 奇点；“闭区域上解析”指在包含该闭区域的更大区域上解析。
- 法则（$f,g$ 区域上解析）：

$$[fg]'=f'g+fg',\quad \left[\frac fg\right]'=\frac{f'g-fg'}{g^2}\ (g\ne0),\quad (z^n)'=nz^{n-1},$$
$$h'(z)=g'(f(z))f'(z),\qquad \varphi'(w)=\frac1{f'(\varphi(w))}\ (f'\ne0).$$

- 条件与失效：商法则需 $g\ne0$；反函数法则需 $f'\ne0$ 且反函数存在连续；$(z^n)'$ 仅对自然数 $n$。
- 推理主线：定义与实函数形式相同，法则可用同样方法证明（教材说明从略）。
- 易混区别：可导是点性质，解析是区域性质。

### 5. 典型例子
**例 1** 证明 $|z|^2$ 在 $z=0$ 可导且导数为 0；$\operatorname{Re}z$ 处处不可导。**例 2** 求 $\dfrac{2z^5-z+3}{4z^2+1}$ 的解析区域与导数。

#### 例题答案区
例 1：$\dfrac{|z|^2}{z}=\bar z\to0$；$\operatorname{Re}z$ 的差商沿两条垂直线分别得 0 与 1，无极限。
例 2：解析区域为全平面除去 $z=\pm\dfrac{\mathrm{i}}2$；$f'(z)=\dfrac{24z^6+10z^4+4z^2-24z-1}{(4z^2+1)^2}$。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| 点可导 ⇒ 点解析 | 漏“邻域”条件 | 邻域内处处可导吗 | 仅区域内二者等价 |
| 奇点 = 无定义点 | 概念记错 | 有定义也可能是奇点 | 奇点 = 不解析点 |
| $(z^\alpha)'=\alpha z^{\alpha-1}$ 直接套 | $\alpha$ 非自然数时未证 | 指数是自然数吗 | 教材范围只用自然数 |

## 柯西—黎曼方程与解析判据

| 字段 | 内容 |
| --- | --- |
| ID / 覆盖知识 ID | KP-02-01-02 / K-000022、K-000025、K-000026 |
| 别名 / 英文 | C-R 方程 / Cauchy-Riemann equations |
| 课程 / 章-节 | 复变函数与积分变换 / 第 2 章 §2.1.3 |
| 能力层级 / 难度 | 应用 / 迁移 / 高 |
| 掌握度 / 置信度 | 未接触 / 低 |
| 来源 / 最近更新 | SRC-001 U00006（原 PDF 48–50 页） / 2026-09-15 |

### 1. 术语对齐
- 学术含义：$u_x'=v_y'$、$u_y'=-v_x'$，配合 $u,v$ 可微即为可导的充要条件。
- 课程含义：把复分析问题化为二元实分析问题的“翻译器”，第二章核心定理。
- 考试识别线索：“讨论可导性与解析性”“求解析区域”“写出 $f'(z)$”“验证 C-R”。
- 速览三行：**定义** $u_x'=v_y'$，$u_y'=-v_x'$；**条件** C-R 成立 **且** $u,v$ 可微；**最易混** C-R 单独成立不充分。

### 2. 先学：前置知识
- 前置卡：[KP-02-01-01](#KP-02-01-01)、[KP-01-02-02](#KP-01-02-02)。
- 快速回顾：偏导记号；二元函数可微的定义与“偏导连续 ⇒ 可微”。
- 前置自测：Q1. 偏导存在与可微的关系？Q2. 求 $u=x^3-3xy^2$ 的 $u_x'$、$u_y'$。
- 前置自测答案（独立区）：A1. 可微 ⇒ 偏导存在，反之不成立。A2. $3x^2-3y^2$ 与 $-6xy$。
- 补齐路径：Q1 答不出须先补高等数学二元微分学，否则无法理解“可微”这一条件。

### 3. 在学：直观理解
- 解决的问题：如何不动用定义就判断可导与解析。
- 一句话解释：要求“沿水平方向与沿竖直方向算出的导数相同”，写成方程就是 C-R。
- 过程：写 $u,v$ → 求四偏导 → 验 C-R → 确认 $u,v$ 可微（实用上查偏导连续）→ 用 (2.4) 写 $f'(z)$。
- 具体案例：$\mathrm{e}^x(\cos y+\mathrm{i}\sin y)$ 满足 C-R 且连续，故处处解析，$f'=f$。
- 反例（必须记住）：$u=v=\dfrac{xy}{x^2+y^2}$（原点补 0）C-R 在原点成立却不连续，故不可导。
- 类比边界：C-R 只管局部解析性，柯西积分定理是第三章的结论，不可混用。

### 4. 在学：正式定义与公式或规则
$$u_x'=v_y',\qquad u_y'=-v_x'\qquad\text{(C-R, (2.3))}$$
- 定理 2.1：在点处可导 $\iff$ $u,v$ 在该点可微且满足 C-R。
- 定理 2.2：在区域 $D$ 内解析 $\iff$ $u,v$ 在 $D$ 内处处可微且满足 C-R。
- 推论：四偏导连续且满足 C-R $\Rightarrow$ 解析（充分不必要）。
- 导数公式：

$$f'(z)=u_x'+\mathrm{i}v_x'=v_y'+\mathrm{i}v_x'=u_x'-\mathrm{i}u_y'=v_y'-\mathrm{i}u_y'.\tag{2.4}$$

- 条件与失效：C-R 必须与可微联用；在一条曲线上满足 C-R 不能推出解析。
- 推理主线：必要性由 $\Delta w=f'(z)\Delta z+o(|\Delta z|)$ 分实虚部得到；充分性代入 $\Delta u,\Delta v$ 的可微展开。
- 易混区别：$u_y'=-v_x'$ 的负号。

### 5. 典型例子
**例** 讨论 $\operatorname{Re}z$、$|z|^2$、$\mathrm{e}^x(\cos y+\mathrm{i}\sin y)$ 的可导性与解析性。

#### 例题答案区
$\operatorname{Re}z$：不满足 C-R，处处不可导、不解析。$|z|^2$：C-R 只在 $(0,0)$ 成立，只在 $z=0$ 可导（$f'(0)=0$），处处不解析。$\mathrm{e}^x(\cos y+\mathrm{i}\sin y)$：满足 C-R 且连续，处处解析，$f'(z)=f(z)$。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| 满足 C-R 就可导 | 漏“可微” | 查可微了吗 | 两者须同时满足 |
| 写成 $u_y'=v_x'$ | 负号漏 | 第二式有负号吗 | $u_y'=-v_x'$ |
| 一条曲线上满足 C-R 就解析 | 解析需邻域 | 是邻域吗 | 一条线不是邻域 |
| 只验一条偏导等式 | 两条都要验 | 两条都验了吗 | 两条都需检验 |

- 具体反例：$u=v=\dfrac{xy}{x^2+y^2}$（原点补 0）满足 C-R 但不连续，故不可导。

### 7. 后续关联
- 后续卡：[KP-02-02-01](#KP-02-02-01)、[KP-02-02-02](#KP-02-02-02)。
- 讲义入口：[第 2 讲 §2.1](学习文档/02-解析函数.md#s2-1)。
- 跨学科：流体力学速度势与流函数满足 C-R，即复势的来源（第七章，样本外）。

### 8. 自测与答案解析
- Q1（复述/识别）：写出 C-R、定理 2.1、2.2 与 (2.4)。
- Q2（基础应用）：用 C-R 判断 $f=x\mathrm{e}^x\cos y+\mathrm{i}x\mathrm{e}^x\sin y$ 的可导性与解析性。
- Q3（迁移）：举一个满足 C-R 却不可导的函数，并说明它为什么不连续。

我的回答：
我不确定的地方：

#### 自测答案区
- A1：见第 4 块。
- A2：注意该函数等于 $x\mathrm{e}^z$。C-R 要求 $\cos y=0$ 与 $\sin y=0$ 同时成立，不可能，故处处不满足 C-R、处处不可导、处处不解析。

  常见错因：只验 C-R 就宣布可导。

### 2. 先学：前置知识
- 前置卡：[KP-02-01-02](#KP-02-01-02)。

### 3. 在学：直观理解
- 解决的问题：解析函数的实部与虚部之间除了 C-R 还有什么约束。
- 一句话解释：再求一次偏导，C-R 就变成两个各自独立的拉普拉斯方程。
- 过程：C-R 两式 → 分别再求偏导 → 用混合偏导相等消去交叉项 → 得拉普拉斯方程。
- 具体案例：$u=x^3-3xy^2$：$6x+(-6x)=0$，调和。
- 反例：$u=x^2+y^2$：和为 $4\ne0$，不调和。
- 类比边界：物理上的“电位/势函数”是调和函数，依赖无源无旋假设。

### 4. 在学：正式定义与公式或规则
- 定义 2.3：$\varphi$ 有二阶连续偏导且 $\varphi_{xx}''+\varphi_{yy}''=0$。
- 定理 2.3：$f=u+\mathrm{i}v$ 在 $D$ 内解析 ⇒ $u,v$ 都调和。
- 定义 2.4：$\varphi,\psi$ 都调和且 $\varphi_x'=\psi_y'$、$\varphi_y'=-\psi_x'$ 时称 $\psi$ 是 $\varphi$ 的共轭调和函数。
- 定理 2.4：$f=u+\mathrm{i}v$ 在 $D$ 内解析 $\iff$ $v$ 是 $u$ 的共轭调和函数。
- 条件与失效：定理 2.3 的证明先使用了“解析函数有任意阶连续偏导”（教材说明以后指明）；定理 2.4 证明从略。
- 易混区别：共轭关系有方向，反向不自动成立。

### 5. 典型例子
**例** 验证 $u=x^3-3xy^2$ 是调和函数。

#### 例题答案区
$u_{xx}''=6x$，$u_{yy}''=-6x$，和为 0，且二阶偏导连续，故调和。方法理由：验证调和只需算两二阶偏导之和并检查连续性。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |

| $u$ 调和 ⇒ 必存在以 $u$ 为实部的解析函数 | 还需单连通 | 区域有洞吗 | 单连通时由曲线积分法保证 |

| 拉普拉斯方程右边写成 $c$ | 方程记错 | 右边是 0 吗 | 等于 0 |

- 具体反例：$u=x^2+y^2$ 全平面连续却不调和——连续不蕴含调和。

| ID / 覆盖知识 ID | KP-02-02-02 / K-000030、K-000031 |
| 别名 / 英文 | 偏积分法、曲线积分法 / constructing analytic functions |

### 1. 术语对齐
- 学术含义：用 C-R 方程从 $u$ 求 $v$（或反之），再由初值条件定常数。
- 课程含义：第二章最典型的大题，考查“用不用得上 C-R”与“会不会凑 $z$”。
- 考试识别线索：“已知调和函数…求解析函数 $f(z)$”“且 $f(z_0)=$…”。
- 速览三行：**定义** C-R 逐次积分或曲线积分；**条件** 先验证调和；曲线积分法还需单连通；**最易混** 积分“常数”是关于另一变量的函数。

### 2. 先学：前置知识
- 前置卡：[KP-02-02-01](#KP-02-02-01)、[KP-02-01-02](#KP-02-01-02)。
- 快速回顾：曲线积分与路径无关；$z^2=x^2-y^2+2xy\mathrm{i}$，$z^3=x^3-3xy^2+\mathrm{i}(3x^2y-y^3)$。
- 前置自测：Q1. 展开 $z^2$ 与 $z^3$。Q2. 曲线积分与路径无关的常用判据？
- 前置自测答案（独立区）：A1. 见上。A2. $\dfrac{\partial P}{\partial y}=\dfrac{\partial Q}{\partial x}$，且区域单连通。
- 补齐路径：出错则回看 [第 2 讲 §2.2](学习文档/02-解析函数.md#s2-2) 与高等数学曲线积分。

### 3. 在学：直观理解
- 解决的问题：只给半个解析函数，能否补出另一半。
- 一句话解释：C-R 给出 $v$ 的两个偏导，等于给出 $v$ 的全微分，于是“积分 + 待定函数”即可。
- 过程（偏积分法）：$v_y'=u_x'$ 对 $y$ 积分 → $v=(\cdots)+\varphi(x)$ → 用 $v_x'=-u_y'$ 定 $\varphi'(x)$ → 定常数。
- 过程（曲线积分法）：$v=\int_{(x_0,y_0)}^{(x,y)}-u_y'\mathrm{d}x+u_x'\mathrm{d}y+C$，路径取“先水平后竖直”折线。
- 具体案例：$u=x^3-3xy^2$ 时 $v=3x^2y-y^3+C$，$f=z^3+\mathrm{i}C$。
- 反例（校验）：若 $f(z)$ 中 $x,y$ 无法合并成 $z$，说明算错。
- 类比边界：与“已知全微分求原函数”完全同类；多连通区域上可能路径相关。

### 4. 在学：正式定义与公式或规则
- 偏积分法：$v=\displaystyle\int u_x'(x,y)\,\mathrm{d}y+\varphi(x)$，再由 $v_x'=-u_y'$ 定 $\varphi'(x)$。
- 曲线积分法（$D$ 单连通、$u$ 调和）：

$$v(x,y)=\int_{(x_0,y_0)}^{(x,y)}-\frac{\partial u}{\partial y}\mathrm{d}x+\frac{\partial u}{\partial x}\mathrm{d}y+C.$$

- 条件与失效：偏积分法需 $u$ 调和；曲线积分法需 $D$ 单连通；常数由 $f(z_0)$ 确定，且为**实**常数。
- 推理主线：由 $\mathrm{d}v=-u_y'\mathrm{d}x+u_x'\mathrm{d}y$ 是全微分，积分即得。
- 易混区别：$\varphi(x)$ 是函数不是常数。

### 5. 典型例子
**例 1** 已知 $u=x^2-y^2+xy$，$f(\mathrm{i})=-1+\mathrm{i}$，求 $f(z)$。**例 2** 已知 $v=\mathrm{e}^x(y\cos y+x\sin y)+x+y$，$f(0)=0$，求 $f(z)$。

#### 例题答案区
例 1：$v_x'=2y-x$，$v_y'=2x+y$，得 $v=-\dfrac12x^2+2xy+\dfrac12y^2+C$，$f(z)=\left(1-\dfrac12\mathrm{i}\right)z^2+\mathrm{i}C$；由 $f(\mathrm{i})=-1+\mathrm{i}$ 得 $C=\dfrac12$，故 $f(z)=\left(1-\dfrac12\mathrm{i}\right)z^2+\dfrac12\mathrm{i}$。
例 2：$u=\mathrm{e}^x(x\cos y-y\sin y)+x+g(y)$，由 $u_y'=-v_x'$ 得 $g(y)=-y+C$，故 $f(z)=z\mathrm{e}^z+(1+\mathrm{i})z+C$；由 $f(0)=0$ 得 $C=0$。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| $\varphi(x)$ 当常数 | 忘记积分产生任意函数 | 对哪个变量积分 | 对 $y$ 积分得 $\varphi(x)$ |
| 常数写成复数 | 混淆实虚部 | 常数在哪一侧 | $C$ 为实常数 |
| 不用 $f(z_0)$ 条件 | 漏一步 | 题给条件用了吗 | 用它定 $C$ |
| 多连通区域用曲线积分法 | 路径可能相关 | 区域有洞吗 | 需另行处理 |

- 具体反例：若把例 1 的 $\varphi(x)$ 当常数，会得 $v=2xy+\dfrac12y^2+C$，代回 C-R 立刻不成立。

### 7. 后续关联

- 讲义入口：[第 2 讲 §2.2](学习文档/02-解析函数.md#s2-2)。

### 1. 术语对齐

- 课程含义：周期性与“$z\to\infty$ 无极限”是两个新性质，后者引出对数多值性。
- 考试识别线索：“计算 $\mathrm{e}^z$”“用指数表示计算乘方/开方”“判断周期性”。
- 速览三行：**定义** $\mathrm{e}^z=\mathrm{e}^x(\cos y+\mathrm{i}\sin y)$；**条件** 全平面解析、$(\mathrm{e}^z)'=\mathrm{e}^z$；**最易混** 周期 $2k\pi\mathrm{i}$，且 $z\to\infty$ 无极限。

### 2. 先学：前置知识
- 前置卡：[KP-01-02-01](#KP-01-02-01)、[KP-02-01-02](#KP-02-01-02)。

- 前置自测答案（独立区）：A1. $1$ 与 $\dfrac\pi2$。A2. 没有。
- 补齐路径：出错则回看 [第 1 讲 §1.2](学习文档/01-复数与复变函数.md#s1-2)。

### 3. 在学：直观理解
- 解决的问题：如何把指数函数推广到复数域并保持“导数等于自身”。
- 一句话解释：实部控制长度（$|\mathrm{e}^z|=\mathrm{e}^x$），虚部控制方向（$\arg\mathrm{e}^z=y$）。
- 过程：写 $z=x+\mathrm{i}y$ → 令 $\mathrm{e}^z=\mathrm{e}^x(\cos y+\mathrm{i}\sin y)$ → 用 C-R 验解析 → 得四条性质。
- 具体案例：$\mathrm{e}^{\mathrm{i}\pi}=-1$。
- 反例：$z\to\infty$ 无极限（沿正实轴趋于 $+\infty$，沿负实轴趋于 $0$）。
- 类比边界：与实指数“单调无周期”的直觉**失效**；与“复平面上的旋转因子”类比成立。

### 4. 在学：正式定义与公式或规则
$$\mathrm{e}^z=\mathrm{e}^x(\cos y+\mathrm{i}\sin y),\qquad \mathrm{e}^{\mathrm{i}y}=\cos y+\mathrm{i}\sin y\ (\text{欧拉公式});$$
$$|\mathrm{e}^z|=\mathrm{e}^x,\quad \operatorname{Arg}\mathrm{e}^z=y+2k\pi,\quad \mathrm{e}^z\ne0,\quad \mathrm{e}^{z_1}\mathrm{e}^{z_2}=\mathrm{e}^{z_1+z_2},\quad (\mathrm{e}^z)'=\mathrm{e}^z;$$
$$\mathrm{e}^{z+2k\pi\mathrm{i}}=\mathrm{e}^z\quad(\text{周期 }2k\pi\mathrm{i}).$$
- 条件与失效：全平面有定义且解析；$z\to\infty$ 无极限；不能写 $\mathrm{e}^z>0$。
- 推理主线：解析性由 C-R 验证；加法公式由定义与两角和公式得到。
- 易混区别：$\mathrm{e}^z\ne0$ 是取值结论，与“极限不存在”不矛盾。

### 5. 典型例子
**例 1** 计算 $\mathrm{e}^{-3+\frac\pi4\mathrm{i}}$。**例 2** 用指数表示计算 $\left(\dfrac{-2+\mathrm{i}}{1+2\mathrm{i}}\right)^{1/3}$。

#### 例题答案区

例 2：$=\mathrm{e}^{\frac{\mathrm{i}}3\left(\frac\pi2+2k\pi\right)}$（$k=0,1,2$），即 $\dfrac{\sqrt3}2+\dfrac{\mathrm{i}}2$、$-\dfrac{\sqrt3}2+\dfrac{\mathrm{i}}2$、$-\mathrm{i}$。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| $\lim\limits_{z\to\infty}\mathrm{e}^z=\infty$ | 沿负实轴趋于 0 | 换方向试试 | 无极限 |
| $\mathrm{e}^z>0$ | 复数无序 | 在写不等号 | 只能写 $\mathrm{e}^z\ne0$ |
| 忘记周期性 | 用实函数直觉 | 有 $2k\pi\mathrm{i}$ 项吗 | 周期为 $2k\pi\mathrm{i}$ |

- 具体反例：$\mathrm{e}^{2\pi\mathrm{i}}=\mathrm{e}^{0}=1$ 而 $2\pi\mathrm{i}\ne0$，说明 $\mathrm{e}^z$ 不是一一映射。

## 对数函数 Ln z 与主值 ln z

| 字段 | 内容 |
| --- | --- |
| ID / 覆盖知识 ID | KP-02-03-02 / K-000033、K-000034 |
| 别名 / 英文 | 复对数、主值 / complex logarithm, principal value |

### 1. 术语对齐
- 学术含义：$\mathrm{Ln}\,z=\ln|z|+\mathrm{i}\operatorname{Arg}z$（多值）；主值 $\ln z=\ln|z|+\mathrm{i}\arg z$（单值）。
- 课程含义：三种对数记号的区别是教材反复强调的易错点；$\ln z$ 的解析区域由 $\arg z$ 的断裂决定。
- 考试识别线索：“求 $\mathrm{Ln}(z)$”“求主值 $\ln z$”“判断解析区域与导数”。
- 速览三行：**定义** $\mathrm{Ln}\,z=\ln z+2k\pi\mathrm{i}$；**条件** $z\ne0$；$\ln z$ 在除去原点与负实轴的平面解析，$(\ln z)'=\dfrac1z$；**最易混** $\mathrm{Ln}\,z^n\ne n\mathrm{Ln}\,z$。

### 2. 先学：前置知识
- 前置卡：[KP-02-03-01](#KP-02-03-01)、[KP-01-02-01](#KP-01-02-01)。
- 快速回顾：$\mathrm{e}^z$ 的周期性与非一一性；主辐角分段公式。
- 前置自测：Q1. 求 $\mathrm{Ln}\,1$ 的全部值。Q2. $\arg(2-3\mathrm{i})$ 是多少？
- 前置自测答案（独立区）：A1. $2k\pi\mathrm{i}$。A2. $-\arctan\dfrac32$。
- 补齐路径：出错则回看 [KP-02-03-01](#KP-02-03-01) 与 [KP-01-02-01](#KP-01-02-01)。

### 3. 在学：直观理解
- 解决的问题：指数函数不一一，反函数自然多值，怎么记账。
- 一句话解释：对数 = “模的对数 + $\mathrm{i}×$ 辐角”，辐角多值带来 $2k\pi\mathrm{i}$。
- 过程：写 $z=r\mathrm{e}^{\mathrm{i}\theta}$、$w=u+\mathrm{i}v$ → 由 $\mathrm{e}^w=z$ 得 $u=\ln r$、$v=\theta+2k\pi$。
- 具体案例：$\ln \mathrm{i}=\dfrac\pi2\mathrm{i}$；$\ln(-2+3\mathrm{i})=\dfrac12\ln13+\mathrm{i}\left(\pi-\arctan\dfrac32\right)$。
- 反例：$\mathrm{Ln}\,z^n=n\mathrm{Ln}\,z$ 不成立（$z=\mathrm{i},n=2$）。
- 类比边界：与实数对数形式相同，但是多值等式，不可移项消去。

### 4. 在学：正式定义与公式或规则
$$w=\mathrm{Ln}\,z=\ln|z|+\mathrm{i}\operatorname{Arg}z\ (z\ne0),\quad \ln z=\ln|z|+\mathrm{i}\arg z,\quad \mathrm{Ln}\,z=\ln z+2k\pi\mathrm{i};$$
$$\mathrm{Ln}(z_1z_2)=\mathrm{Ln}\,z_1+\mathrm{Ln}\,z_2,\qquad \mathrm{Ln}\frac{z_1}{z_2}=\mathrm{Ln}\,z_1-\mathrm{Ln}\,z_2\quad(\text{多值相等});$$
$$\frac{\mathrm{d}}{\mathrm{d}z}(\ln z)=\frac1z\quad(\text{除去原点及负实轴}).$$
- 条件与失效：$z\ne0$；原点与负实轴上分支不连续故不可导；$\mathrm{Ln}\,z^n=n\mathrm{Ln}\,z$ **不成立**。
- 推理主线：指数函数周期性 → 反解得多值；反函数求导法则给出 $1/z$。
- 易混区别：$\mathrm{Ln}\,z$（多值）与 $\ln z$（主值，单值）。

### 5. 典型例子
**例 1** 求 $\mathrm{Ln}(-1)$、$\mathrm{Ln}(2-3\mathrm{i})$。**例 2** 计算 $\ln \mathrm{i}$ 与 $\ln(-2+3\mathrm{i})$。

#### 例题答案区
例 1：$\mathrm{Ln}(-1)=(2k+1)\pi\mathrm{i}$；$\mathrm{Ln}(2-3\mathrm{i})=\dfrac12\ln13-\mathrm{i}\left(\arctan\dfrac32+2k\pi\right)$。
例 2：$\ln \mathrm{i}=\dfrac\pi2\mathrm{i}$；$\ln(-2+3\mathrm{i})=\dfrac12\ln13+\mathrm{i}\left(\pi-\arctan\dfrac32\right)$。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| $\mathrm{Ln}\,z^n=n\mathrm{Ln}\,z$ | 多值集合不等 | 把 $2k\pi$ 提出来了？ | 不成立 |
| $\ln z$ 在全平面解析 | 漏负实轴 | 解析区域写全了吗 | 除去原点及负实轴 |
| 象限判断错 | 用 $x>0$ 公式处理 $x<0$ | 在第几象限 | 用主辐角分段公式 |
| 把 $2k\pi\mathrm{i}$ 写成 $2k\pi$ | 漏 $\mathrm{i}$ | 有 $\mathrm{i}$ 吗 | 相差 $2k\pi\mathrm{i}$ |

- 具体反例：$\mathrm{Ln}\,\mathrm{i}^2=\mathrm{i}(\pi+2k\pi)$，而 $2\mathrm{Ln}\,\mathrm{i}=\mathrm{i}(\pi+4m\pi)$，取值集合不同。

### 1. 术语对齐
- 学术含义：$z^\alpha=\mathrm{e}^{\alpha\mathrm{Ln}z}$（$z\ne0$）；因 $\mathrm{Ln}\,z$ 多值，一般也是多值函数。
- 课程含义：把“幂”从整数扩展到任意复常数 $\alpha$ 的唯一定义入口；样本内只到“$\alpha$ 为正整数时单值”一句。
- 考试识别线索：“用定义计算 $z^\alpha$”“判断是否单值”“说明 $\alpha$ 取何值时单值”。
- 速览三行：**定义** $z^\alpha=\mathrm{e}^{\alpha\mathrm{Ln}z}$；**条件** $z\ne0$（$\alpha$ 为正实数且 $z=0$ 时补充 $z^\alpha=0$）；**最易混** 一般多值，只有整数 $\alpha$ 才单值。
- **受限提示**：样本在此句后截断，$\alpha$ 为分数、负整数、纯虚数时的多值与单值分支**不在本次资料范围内**。

### 2. 先学：前置知识
- 前置卡：[KP-02-03-02](#KP-02-03-02)、[KP-01-02-03](#KP-01-02-03)。
- 快速回顾：$\mathrm{Ln}\,z=\ln z+2k\pi\mathrm{i}$；$\mathrm{e}^{2k\pi\mathrm{i}}=1$。
- 前置自测：Q1. 写出 $\mathrm{Ln}\,z$ 的通式。Q2. 判断 $\mathrm{e}^{4k\pi\mathrm{i}}$ 是否恒为 1。
- 前置自测答案（独立区）：A1. $\ln|z|+\mathrm{i}\operatorname{Arg}z$。A2. 恒为 1。

### 3. 在学：直观理解
- 解决的问题：实数中“$\alpha$ 个 $z$ 相乘”只对整数有意义，如何定义任意复指数的幂。
- 一句话解释：借指数与对数把幂“翻译”出来，代价是继承了对数的多值性。
- 过程：写 $z^\alpha=\mathrm{e}^{\alpha\mathrm{Ln}z}$ → 代入 $\mathrm{Ln}\,z=\ln|z|+\mathrm{i}(\arg z+2k\pi)$ → 看 $\mathrm{e}^{\mathrm{i}2k\pi\alpha}$ 是否恒为 1。
- 具体案例（样本内可算）：$(1+\mathrm{i})^2=\mathrm{e}^{2\mathrm{Ln}(1+\mathrm{i})}=\mathrm{e}^{\ln2+\mathrm{i}(\frac\pi2+4k\pi)}=2\mathrm{i}$（单值）。
- 反例：$\alpha=\dfrac12$ 时 $\mathrm{e}^{\mathrm{i}\pi k}=(-1)^k$ 不恒为 1，故多值（该情形样本未讲，仅作概念提示，不作为考核要求）。
- 类比边界：与“整数次幂 = 连乘”类比只在 $\alpha$ 为自然数时成立。

### 4. 在学：正式定义与公式或规则
$$z^\alpha=\mathrm{e}^{\alpha\,\mathrm{Ln}\,z}\quad(\alpha\ \text{为复常数},\ z\ne0);\qquad \text{规定：}\alpha\ \text{为正实数且}\ z=0\ \text{时}\ z^\alpha=0.$$
$$\alpha=n\ (\text{正整数}):\quad z^n=\mathrm{e}^{n\mathrm{Ln}z}=|z|^n\mathrm{e}^{\mathrm{i}n\arg z}\quad(\text{单值}).$$
- 条件与失效：$z\ne0$；一般多值；只有 $\alpha$ 为整数时单值（样本内只给出正整数情形）。
- 推理主线：$\mathrm{e}^{\mathrm{i}2kn\pi}=1$ 对一切整数 $k$ 成立，故 $k$ 不影响取值，函数单值。
- 易混区别：$z^\alpha$ 不等于“$z$ 连乘 $\alpha$ 次”。

### 5. 典型例子
**例** 用定义 2.7 计算 $(1-\sqrt3\mathrm{i})^3$。

#### 例题答案区
$1-\sqrt3\mathrm{i}=2\mathrm{e}^{-\mathrm{i}\frac\pi3}$，故 $(1-\sqrt3\mathrm{i})^3=\mathrm{e}^{3\left[\ln2+\mathrm{i}\left(-\frac\pi3+2k\pi\right)\right]}=8\mathrm{e}^{-\mathrm{i}\pi}\mathrm{e}^{6k\pi\mathrm{i}}=-8$（单值，因 $\alpha=3$ 为整数）。与直接用 (1.12) 得的结果一致。

### 6. 易错点与反例
| 错误 | 原因 | 诊断提示 | 修正 |
| --- | --- | --- | --- |
| 认为 $z^\alpha$ 一定单值 | 忽略多值性 | $\alpha$ 是整数吗 | 只有整数才单值 |
| 用定义时丢掉 $k$ 项 | 漏 $\mathrm{Ln}$ 的多值 | 写了 $2k\pi$ 吗 | 代全 $\mathrm{Ln}\,z$ |
| 把 $z^\alpha$ 写成 $z$ 连乘 | 概念迁移错误 | $\alpha$ 是整数吗 | 定义用 $\mathrm{e}^{\alpha\mathrm{Ln}z}$ |
| 把 $\mathrm{e}^{\mathrm{i}2k\pi\alpha}$ 当恒为 1 | $\alpha$ 非整数时错 | $\alpha$ 是整数吗 | 只有整数时恒为 1 |

- 具体反例：$\mathrm{e}^{\mathrm{i}\pi k}=(-1)^k$ 随 $k$ 变化，说明 $\alpha=\dfrac12$ 时 $z^{1/2}$ 多值（样本未讲，仅作理解用）。
