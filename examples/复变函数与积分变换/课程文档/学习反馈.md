# 学习反馈

本文件保存**真实作答与错因**，是判断掌握度的唯一依据。卡片里的“掌握度快照”只放当前状态，历史记录全部留在本文件。

## 使用方式

1. 做完题后，把**原题、你的答案、你确定/不确定的地方**写进对应章节的“作答记录”。
2. 对照答案后，填写“错因归类”与“下一步动作”。
3. 每完成一轮（当天 / 第 3 天 / 第 7 天 / 考前），在“复习轮次记录”里加一行。

**未作答时不要填写掌握度**：`核心知识点.md` 的置信度保持在“低”，不做无证据的升级。

## 错因归类标签（填写时选一个）

| 标签 | 含义 | 回看入口 |
| --- | --- | --- |
| 概念不清 | 说不清定义、条件、适用边界 | 对应节的“知识要点”与“深度解析” |
| 会背不会用 | 公式记得，题目不会下手 | 对应节“例题答案区”，再做一道同型题 |
| 步骤不稳 | 思路对但符号、常数、象限出错 | 对应节“易错辨析”表，逐条写出诊断提示 |
| 前置缺口 | 卡在包内前置知识上 | 按 [学习路径.md](学习路径.md) 的“必要前置与补学”回补 |
| 表述不规范 | 结论对但不符合课程约定（如漏写解析区域） | 对应节“来源与卡片入口”中的约定说明 |
