## 已实现范围

技能包含 18 个文件：主文件、界面元数据、7 份按阶段加载的规范、4 份产物模板、4 个命令脚本及 1 个共用工具模块。

完整流程为：学习目标与资料范围确认 → 基础与前置确认 → 分批读取全部资料 → 分章知识整理及完整汇编 → 前置优先的学习路径 → 逐章完整学习文档 → 核心知识卡片 → 覆盖及内容验收。

输出包含用户要求的 `知识内容.md`、`学习路径.md`、`学习文档/` 和 `核心知识点.md`，并配备学生入口、需求记录、资料清单、反馈和质量报告。

工作区保存源文件哈希、提取内容、章节分片、知识索引、覆盖记录和生成进度。原件不移动；资料变化会使范围确认失效并提示更新。知识汇编完整保留分片知识，只修正合并后相对链接的位置，不进行二次摘要。

## 脚本实际能力

| 功能 | 当前实现 |
| --- | --- |
| 资料盘点 | 按明确输入范围建清单；稳定来源 ID、哈希、重复文件和内容变更检测 |
| PDF | 使用可用的 pypdf 提取文字，pypdfium2 分批渲染页面；保留逐页视觉复核状态 |
| 扫描件及图片 | 保存页面或原图；本地 Tesseract 可选，未配置时交由视觉阅读或记录阻塞 |
| PPTX | 按幻灯片顺序提取文字、备注、媒体和必要原始 XML；布局及图示关系仍需视觉复核 |
| EPUB | 按 spine 顺序读取，并补入未列在 spine 中的 HTML 附注，提取图像及原 XHTML |
| DOCX | 提取正文、脚注、尾注、表格文字及媒体；复杂布局和公式需复核 |
| 文本资料 | TXT、Markdown、HTML、CSV 按字符块提取，保留位置 |
| 知识合并 | 从已完成分片生成完整汇编、目录和可用的相对链接；不完整时默认拒绝完整汇编 |
| 结构验收 | 检查资料版本、覆盖、依赖、知识及卡片映射、产物、文件和锚点链接、汇编一致性 |

PPT/DOC 旧格式、受保护电子书及其他未支持格式会显式标为阻塞，需使用环境已有兼容工具或提供可读导出版本。脚本不会把未解析文件当作已读。

1. 资料归档目录及完全重复文件识别。

3. 源文件变更后拒绝继续使用过期提取版本。
4. DOCX 正文和表格列内容提取。
5. EPUB 阅读顺序及 spine 外附注。
6. 拒绝不完整汇编及越出课程目录的路径。
7. 来源 ID 稳定性、确认失效及学习者记录保留。
8. 混合 PDF 的文字页、扫描页和页面渲染。
9. PPTX 正文及备注提取。
10. 长文本分批续作，重建后无字符丢失。
11. 未支持格式保持阻塞并记录原因。
12. 有效课程数据结构及完整知识合并。
13. 漏读、断链和汇编与分片不一致的检测。
14. 未复核视觉内容及前置依赖循环的检测。

测试用的是临时生成的小型资料及结构样本，不是完整真实教材的教学效果评估。没有声称已验证所有学科、所有文件格式或学习效果。

## 已知边界

- 当前环境未配置本地 Tesseract，自动 OCR 的真实识别效果未测试；已验证扫描页不会被当作空白而跳过，并能保留供视觉阅读的页面图像。
- PPTX、DOCX 的完整页面渲染交由环境已有工具；当前脚本直接提供文本、媒体和结构，不能独立证明布局信息已完整理解。
- 结构脚本无法证明概念、推导、答案、教学顺序和实际渲染均正确。技能要求模型在分章写作及最终交付时完成内容复核。
- 知识浓缩和课程写作由调用技能的模型执行，脚本没有另行绑定模型 API，也没有自动上传资料。

## 调用方式

在支持技能调用的对话中附上教材或资料路径，使用：

```text
使用 $better-learning，把这些资料整理成完整的自学文件包。
先确认我的学习目标、资料是否齐全，以及我的基础知识。
```

继续同一课程时指定课程目录，技能从进度与索引恢复。新增资料后重新确认范围并更新受影响内容。
