# better-learning

**把一堆教材，变成一套能自己学下去的课程。**

面向大学生的自学课程生成 Skill：将教材、PDF（含扫描件）、电子书、课件和题库，整理为包含**学习路径、逐章讲义、练习与答案、核心知识卡片、知识链接**的 Markdown 课程文件包。

围绕你的学习目标与已有基础，回答三个问题：**先学什么、怎么学懂、怎样知道自己真的会了。**

## 为什么做这个项目

很多大学生自学时遇到的困难，来自教材与课堂之间没有补齐的那一段：

- 公式给出来了，中间的推导却被一句“显然”带过。
- 前置知识散落在其他章节，读到一半才发现自己缺了基础。
- 教材、老师的课件、习题和答案各放一处，需要不停切换、拼接。
- 看例题觉得会了，换一道题又不知道从哪里开始。
- 考前能背重点，过后却说不清知识之间的联系。

better-learning 想拆掉这些“防自学”门槛：补齐必要解释，理清先修关系，把分散资料组织成可以一步步走通的学习过程。

**让教材里的知识，更容易被一个没有老师在旁边的学生学会。**

## 你会得到什么

| 产物 | 解决的问题 |
| --- | --- |
| 学习路径 | 根据目标和基础安排先后顺序，先补前置，再逐步深入 |
| 逐章学习文档 | 讲清概念、推理、适用条件和边界，包含例题与易错辨析 |
| 自测与答案解析 | 用实际作答检查理解，并给出错因和回看位置 |
| 核心知识卡片 | 集中复习定义、条件、例子、前置与后续关联 |
| 知识内容 | 汇集资料中的独立知识，作为课程编写与核查的依据 |
| 逐文件资料转写 | 每份输入对应一份 Markdown，保留来源定位 |
| 知识链接 | 连接前置知识、相关讲义、核心卡片与练习入口 |
| 学习反馈与质量报告 | 记录卡点、下一步，以及资料覆盖和未解决的问题 |

讲义按“**问题 → 知识 → 解释 → 例题 → 易错点 → 自测 → 答案 → 过关标准 → 来源**”组织，帮助你完成理解、练习、纠错和复习。

## 适合怎样使用

- **从零自学一门大学课程**：提供教材和已有基础，建立完整学习路线。
- **跟不上课堂进度**：结合教材与课件，找出前置缺口，补上必要解释。
- **准备期末考试**：结合题库梳理知识和题型，同时保留适用条件与解题依据。
- **整理长期知识库**：把学过的内容沉淀为可以继续编辑、链接和复习的 Markdown 文件。

## 工作流程

1. **确认目标与资料范围**：明确要学到什么程度，并确认收到的文件是否齐全。
2. **了解基础与前置知识**：记录已掌握、薄弱和未知内容，用于后续课程编排。
3. **拆分并转写资料**：机械准备页面、文字与图片，由宿主内可写的子 Agent 分批处理，每个单元完成后立即保存。
4. **逐文件合成 Markdown**：校验落盘结果，处理失败与待核实项，再合成每份来源的完整转写。
5. **按章节整理知识**：分章读取、去重和组织，保留独立知识、条件、例外与不同题型的方法，合成知识库。
6. **编排并生成课程**：以知识库为核心，生成学习路径、逐章讲义和核心知识卡片。
7. **验收与交付**：检查覆盖、依赖、答案和链接，整理成便于学习的课程目录。

### 扫描 PDF 怎么处理？

处于对高可靠性的要求，所有 PDF 和图片都走视觉转写路径；Word、PPT 等支持格式中的文字与内嵌图片按原位置拆分处理。

看图与转写交给宿主子 Agent，正文直接写入文件。主代理负责调度，只接收路径、数量和状态，避免把整本教材的图片不断累积在主对话里。

默认每批最多 8 个同来源连续单元、最多并发 2 批，可按页面密度缩小批量。**隔离单位是批次**，批内仍有上下文开销。失败时可按单元重试，已完成内容不重复追加。

当前流程不依赖本地 OCR 模型，也不通过额外的外部 CLI 启动转写。

## 快速开始

### 使用条件

- 一个支持 Skill、能创建**可看图且可写文件的子 Agent**的宿主。
- 本地可用的 Python 与文档处理依赖。核心依赖包括 Pillow、pypdfium2；PDF 辅助文本读取使用 pypdf。
- 宿主模型所需的正常登录、权限和可用额度。

目前提供 Codex、CodeBuddy、Claude 的[宿主适配说明](better-learning/references/host-adapter.md)。实际可用性以当前宿主工具和写权限探针为准。

### 安装

下载并解压本仓库，将其中包含 `SKILL.md` 的 **`better-learning/` 文件夹**放入宿主可发现的 Skills 目录，再按宿主方式加载。

核心文档处理依赖可以安装到你供宿主使用的 Python 环境：

```bash
python -m pip install Pillow pypdfium2 pypdf
```

### 开始一次学习任务

在支持相应调用语法的宿主中使用 `$better-learning`，或直接要求它使用此 Skill。例如：

> 使用 better-learning，把我提供的高等数学教材、老师的课件和期末题库，整理成一套可以独立自学的课程。  
> 我的目标是理解核心概念，并能独立完成常见题型。  
> 我学过高中数学，但函数和三角公式比较薄弱。每天能学习 1 小时，计划用 4 周完成。  
> 请先确认资料是否齐全和我的前置知识，再安排学习路径。结果保存为 Markdown，方便放进 Obsidian。

你不必先把所有需求写得很完整，Skill 会先与你确认目标、资料范围和基础。

## Obsidian 友好

课程以 Markdown 文件组织，公式使用 LaTeX，讲义、卡片与前置知识之间建立链接。可以把课程目录放进自己的 Obsidian 笔记库，继续补充课堂笔记、个人理解和错题记录。

优先使用相对文件链接，方便把整套课程一起保存和迁移。无需为了阅读正文先配置专用数据库或自定义笔记系统。

当前核心卡片集中存放在一个 `核心知识点.md` 中，通过索引和锚点定位；**第一版不默认把每个概念拆成一个独立文件**。细粒度跳转、HTML 折叠和具体公式显示仍需在实际阅读器中检查。知识链接的目标是帮助找到关联内容，不承诺自动生成经过语义验证的 Obsidian 知识图谱。

## 第一版的边界

- **需要 Agent 宿主。** 这是一套 Skill 与辅助脚本，依赖宿主的模型、子 Agent 和文件工具。
- **识别结果需要核查。** 模糊扫描、复杂公式、表格和图形关系可能产生错误；无法确认的内容会保留待核实状态。
- **不同格式的支持有边界。** 受保护文件、旧版 Office 格式、部分矢量图片及无法可靠定位的混合内容，可能需要先转换或补充处理。
- **会消耗宿主模型额度。** 不需要另接一套视觉 API key，不代表离线运行或没有调用成本。
- **生成资料不等于已经掌握。** 学习效果仍需要通过独立作答、自测和反馈来检查。

欢迎通过 Issue 反馈实际课程中的问题：缺失的前置知识、难以理解的讲义、错误的知识链接、转写失败或不合适的学习路径。具体的输入形式、预期结果和问题位置，会更有助于改进。
